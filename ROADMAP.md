## A — аудит: первичный завершён, внешние проверки открыты
Подтверждены: destructive fallback в шести местах; сохранение плановых, а не отмеченных подходов; пять фиксированных кнопок подходов; отсутствие восстановления сессии; нет cloud-sync тренировок; нет Firebase Rules в репозитории; удаление аккаунта оставляет облачные данные; лог URL новостей содержал API key. Подробности в docs/AUDIT.md. Исследование конкурентов заблокировано HTTP 403, не считается завершённым.

## P0/P1 — следующий этап надёжности
- Исправить полное удаление аккаунта через доверенный backend с повторяемыми шагами, reauthentication и Rules.
- Outbox + UUID + revisions + конфликты + emulator security tests, затем включить sync.
- Экспорт через Storage Access Framework, журнал истории с фильтрами и полноценные графики 7/30/90/365/all.
- Стабильная идентичность упражнений и группы мышц/оборудование; перенос legacy записей без слияния разных движений.
- Выравнивание профиля, заметок, карт и авторизации с дизайн-системой.

## P2 — один проверяемый продуктовый эксперимент
Gym-Aware Training: явный ввод пользователем оборудования конкретного зала, фильтр собственных упражнений, объяснение каждой предложенной замены и подтверждение пользователя. Карты не предоставляют инвентарь. Тестировать на 5–8 пользователях до расширения.
Затем: собственные программы, календарь, повторения, добровольные напоминания, onboarding, timeline. Никаких выдуманных рекомендаций/изображений.

## P3 — коммерциализация
Проверка ценности Pro; server-verified entitlements, expiry/revocation, правила магазинов и региона. Платежи — только после отдельного согласования. Coach Platform после подтверждения спроса. Существующие данные и функции остаются доступными.
