# Changelog

## 2.1-dev — текущая разработка
- Идентичность ANTI-GYM, режимы Normal/Bro/Chaos и отключаемые редкие реплики.
- XP за отдельные тренировочные дни, прозрачные уровни и короткий опциональный эффект.
- Уникальный UUID завершённой сессии и защита от позднего воссоздания черновика.
- Сохранён Java/Firebase/Room/MapKit стек и Android API 24.
- Dashboard из реальной локальной истории и нижняя навигация.
- Семантическая светлая/тёмная палитра Material 3.
- Сохранение и восстановление тренировочной сессии в Room.
- Независимое выполнение, вес, повторения и разминка каждого подхода, добавление подходов.
- Транзакционное сохранение фактической работы вместо плановой нагрузки.
- Миграция базы 6→7 без destructive fallback.
- Объяснение изменения рабочего веса по собственным данным, без автоматического назначения нагрузки.
- Тесты расчётов и миграции/идемпотентности; точные результаты см. README.
