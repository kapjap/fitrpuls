# Дизайн-система ANTI-GYM: «Твой ритм»

Идентичность: личное пространство тренировочного развития, спокойный спортивный интерфейс без социальной гонки. Не копия интерфейса конкретного конкурента.

Тёмная палитра: фон #101310, поверхность #1B211B, поднятая поверхность #252E24, основной текст #F1F5ED, вторичный #ADB8A7, лайм #B9EE73, текст на акценте #142008.
Светлая: фон #F4F6F2, поверхность #FFFFFF, поднятая поверхность #E8EDE4, основной текст #172019, вторичный #52604F, акцент #396515, текст на акценте #FFFFFF.

Семантические токены в values/colors.xml и values-night/colors.xml. Material 3 DayNight сохраняет системный выбор и существующие настройки пользователя. Не принуждаем текущих пользователей к новой теме.

Шкала: заголовок 32sp, секция 22sp, упражнение 20sp, основной текст 16sp, подпись 12–14sp. Отступы 8/16/24dp, карточка 24dp, минимальная цель нажатия 48dp. Кнопки/диалоги/чекбоксы используют нативные компоненты. Отдельные подходы — вертикальные строки с редактированием и независимым выполнением.

Главная прокручивается; активная тренировка оставляет растягиваемую область упражнений и компактный отдых. Нижняя навигация: Главная / Тренировки / Прогресс / Залы / Профиль. Новости остаются дополнительным разделом. Пустая история не подменяется демоданными; dashboard показывает состояние загрузки до ответа Room.

Переход на систему постепенный. Legacy профиль, карты, заметки, авторизация и новости сохраняют прежнюю разметку и часть прежнего оформления. Полноценные графики, calendar/bottom-sheet компоненты и анимации ещё не реализованы. Старый design/home-preview.html относится к предыдущему косметическому этапу, не является актуальным скриншотом приложения. Нужны проверки контраста всех legacy-состояний, TalkBack, увеличенного шрифта, 320dp/планшета/альбомной ориентации и API 24/35.

Правило ANTI-GYM: главная может быть необычной, тренировка максимально практична, достижение эмоционально. 90% удобство / 10% характер. Bro по умолчанию, Normal/Chaos и выключение юмора в настройках. См. docs/PRODUCT.md.
