# Дизайн-система ANTI-GYM: «Твой ритм»

Идентичность: личное пространство тренировочного развития, спокойный спортивный интерфейс без социальной гонки. Не копия интерфейса конкретного конкурента.

Тёмная палитра: фон #101310, поверхность #1B211B, поднятая поверхность #252E24, основной текст #F1F5ED, вторичный #ADB8A7, лайм #B9EE73, текст на акценте #142008.
Светлая: фон #F4F6F2, поверхность #FFFFFF, поднятая поверхность #E8EDE4, основной текст #172019, вторичный #52604F, акцент #396515, текст на акценте #FFFFFF.

Семантические токены в values/colors.xml и values-night/colors.xml. Material 3 DayNight сохраняет системный выбор и существующие настройки пользователя. Не принуждаем текущих пользователей к новой теме.

Шкала: заголовок 32sp, секция 22sp, упражнение 20sp, основной текст 16sp, подпись 12–14sp. Отступы 8/16/24dp, карточка 24dp, минимальная цель нажатия 48dp. Кнопки/диалоги/чекбоксы используют нативные компоненты. Отдельные подходы — вертикальные строки с редактированием и независимым выполнением.

Главная прокручивается; активная тренировка оставляет растягиваемую область упражнений и компактный отдых. Нижняя навигация: Главная / Тренировки / Прогресс / Залы / Профиль. Новости остаются дополнительным разделом. Пустая история не подменяется демоданными; dashboard показывает состояние загрузки до ответа Room.

Переход на систему постепенный. Legacy профиль, карты, заметки, авторизация и новости сохраняют прежнюю разметку и часть прежнего оформления. Полноценные графики, calendar/bottom-sheet компоненты и анимации ещё не реализованы. Старый design/home-preview.html относится к предыдущему косметическому этапу, не является актуальным скриншотом приложения. Нужны проверки контраста всех legacy-состояний, TalkBack, увеличенного шрифта, 320dp/планшета/альбомной ориентации и API 24/35.

Правило ANTI-GYM: главная может быть необычной, тренировка максимально практична, достижение эмоционально. Sport Editorial Minimalism: 70% чистый спортивный минимализм, 25% андеграундная выразительность, 5% RPG-атмосфера. Это фитнес-приложение, не игра. Bro по умолчанию, Normal/Chaos и выключение юмора в настройках. См. docs/PRODUCT.md.

Активная тренировка: прямые числовые поля «кг» / «Повторы», номер подхода открывает действия рабочего/разминочного типа и удаления; отметка выполнения отдельно справа. Внизу компактный отдых с явными состояниями. При клавиатуре приоритет получает список. Статус локального черновика не выдаётся за облачную синхронизацию. Завершение требует подтверждения и корректных значений. Никаких шуток между подходами.

## Вход в клуб: приветствие, вход, регистрация
Локальная тёмная редакционная палитра `welcome.xml`; глобальная тема приложения не меняется. Общий знак `ag_club_mark.xml` — лаймовая вертикаль, две смещённые отрицательные прорези, открытый асимметричный хвост. Сохранять пропорции 32:144; крупная версия 32×144dp, форменная 20×90dp. Знак декоративный, не действие. Использовать на тёмном фоне без glow/вращения/пульсации.

Приветствие сохраняет огромный двухстрочный бренд и смещение; формы используют компактные заголовки и постоянные подписи, не лозунги. Общие AuthField/AuthAction/AuthLink и локальный ThemeOverlay.AntiGym.Auth. Переходы 180 мс, небольшой горизонтальный сдвиг, отключаемые системной настройкой. Приоритет поля, клавиатуры, фокуса и доступных кнопок; AuthScreenUi не содержит Firebase-логики.

## Главная: editorial dashboard
Тёмный прямоугольный плакат без одинаковых карточек: ANTI / GYM со сдвигом второй строки, рядом реальный уровень и тонкая шкала XP, вертикальный знак. Один лаймовый CTA. Недельные показатели в трёх колонках, последний результат под линией. Объяснения остаются в диалоге, не в основной композиции. Шкала — представление существующего интервала 500 XP; общая сумма, остаток и LEVEL UP не заменяют друг друга. Обновления анимируются только при разрешённых эффектах, без анимации фиктивных значений при загрузке.

## Список и создание тренировок
Компактные строки с разделителями вместо поднятых округлых карточек; один CTA создания в списке. Формы с постоянными подписями и сгруппированными числовыми полями, прямоугольные кнопки с радиусом 4dp. TrainingPrimary/TrainingSecondary/TrainingField используют семантические day/night цвета; основной акцент лаймовый. Вложенный список упражнений прокручивается вместе с формой. Никаких LEVEL/XP на рабочих формах. Insets получает один корневой контейнер, чтобы не удваивать отступ нижней навигации.
