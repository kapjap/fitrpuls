# ANTI-GYM / fitrpuls

Развитие исходного Android-приложения 2.0. Текущая версия **2.1-dev**, инженерный этап, не готовый коммерческий релиз. Основной язык Java, XML/Material 3, Room, Firebase Auth/Realtime Database, Яндекс MapKit. minSdk 24, compile/target SDK 35, AGP 8.8.2, Gradle 8.10.2.

## Сборка
Установите JDK 17+ (в этой среде проверяется JDK 21), Android SDK Platform 35 и Build Tools 35. Укажите sdk.dir в локальном local.properties или ANDROID_HOME. Используйте существующую Firebase-конфигурацию; не подменяйте её демонстрационными ключами.

```
bash gradlew :app:assembleDebug :app:testDebugUnitTest :app:assembleDebugAndroidTest
# На подключённом тестовом устройстве:
bash gradlew :app:connectedDebugAndroidTest
```

При корпоративном proxy настройте JVM proxy и доверенное хранилище CA в пользовательском Gradle config, не отключайте TLS. Ключи/пароли не добавляйте в Git. Автоматическая публикация/подписанный release не настроены.

## Проверка пользовательского сценария
Войти → Тренировки → создать шаблон → открыть → изменить вес/повторы отдельного подхода → отметить его → вернуться → снова открыть тот же шаблон → проверить восстановление → завершить → посмотреть главную/прогресс. Незавершённые подходы не должны попадать в итог. Проверить второй аккаунт, режим самолёта с существующей авторизацией и повторное завершение.

## Обновление с 2.0
База fitpulse_database сохраняет прежние таблицы. Миграция 6→7 добавляет черновики и признак разминки. История не удаляется. Debug APK не обновит установленный release с другой подписью; для проверки настоящего обновления нужен тот же сертификат владельца. Не удалять установленное приложение ради теста сохранности данных.
